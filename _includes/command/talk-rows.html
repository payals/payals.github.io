{%- comment -%} command/talk-rows.html: the talks list, one row per talk family (L1), each a
that opens to its venues, dates, caveats and links (L2). Used by the home Talks drawer and by /talks/, so both read the same records the same way. Families come from data/talk_families.json in first-appearance order over data/talks.json (upcoming first, then past, as that file is ordered); a talk in no family is a one-venue row. Needs command/data.html first. The open body adds only what the row does not show: the full date (the row shows the year), venues, caveats and links. The topic is the row's shape. Hover (fine pointer) and keyboard focus slide the row and show its tail (the link kinds inside) with no reflow; click, Enter or tap opens it. Works with JavaScript off: it is plain
. A #talk- link then scrolls to the row and marks it (.row:target) without opening it; command.js opens it. data-records lists the talks.json record ids in the family, so an old home link to /# still finds its row (command.js, legacy ids). {%- endcomment -%}
