## Repo Surprises (cont.)
- 2026-09-25 Rouge splits fenced-code text into spans in the built HTML, so `grep -q '<phrase inside a code block>' _site/.../index.html` fails even when the phrase rendered; strip tags (or grep the markdown source) before asserting on code-block content. GitHub Pages builds in UTC with `future: false`: a post dated 21:00 -0400 is tomorrow in UTC and gets skipped (and would take a /MM/DD+1/ permalink); keep post times such that the UTC date matches the local date.
- 2026-09-25 `~/Projects/obsidian-lore` (Pi's Lore vault, `Accomplishments.md`) was not cloned locally although the `obsidian-lore` skill assumes that path; `gh repo clone payals/obsidian-lore` fixed it. `lore-onboarding` is at `~/Projects/lore-onboarding`. The `skill-search` MCP server (find_skills) failed to connect (ENOENT on `~/.claude/skills/mcp-skill-search/run.sh`), so the skill protocol cannot run; say so instead of inventing skills.
- 2026-09-23 A long CDP script (many history.back/forward + dialog opens in one tab) wedged headless Chrome entirely (even /json/list hung); split checks into short scripts, one tab each, and wrap runs in `timeout`. `container-type` (layout containment) makes an element a containing block like `transform` does: keep it off ancestors of the stretched `.pl-link::after` (scoped to `.row > summary .row-meta`).
- 2026-09-23 A hover `transform` on `.row-main` made it the containing block of the stretched `.pl-link::after`, so on /blog/ a click on the date column did nothing (only the title column opened the post). Never transform an ancestor of a stretched-link overlay; tint instead.
- 2026-09-23 CDP `Emulation.setEmulatedMedia {media:"print"}` does not fire `beforeprint`, so a JS-only print fix is invisible to print emulation; put print state (e.g. unhiding filtered rows) in `@media print` CSS. `grep` through the rtk hook mangles output (per-line pseudo-files); use `/usr/bin/grep` for line output.
- 2026-09-23 Home hash routing runs in the deferred command.js before `c-ready`, so the prompt (.js-only) is still display:none and `cmd.focus()` fails; Chrome's load-time fragment scroll then resets drawer scroll and drops focus (the canonical `/#talks` load also ends with focus on body). Wait for `load` plus two rAFs before any focus or scrollIntoView tied to a load hash.
- 2026-09-23 `_includes/post-footer.html` is part of each post's `content`, so its markup ships in feed.xml; keep page-only attributes (id/tabindex focus targets) out of it and add them in `_layouts/post.html` with a `replace_first` on the body. Post h2 "#" anchors sit inside the h2, so the h2 needs `aria-labelledby` on a span of its own text or screen readers hear the link name in every heading.
- 2026-09-23 Jekyll renders posts oldest first, so a shared include rendered inside a post's layout sees the posts after it as raw markdown (`post.content`); word counts differed by page (search-index minutes 11 vs 12). Keep render-order-dependent values out of includes that post pages render. Jekyll include params cannot be `tag[1]`; assign it first.
