{%- comment -%} command.html: the one base layout of the "command-first" design system (redesign direction C, 2026-09). Every page on the site renders through it: home, /talks/, /cv/, the blog (post, page and blog layouts sit on top of it), /reading/, the evidence pages and the 404. The one exception is the standalone deck under /talks/pgsummit-2026/, which is static files with no front matter. Tokens, type, status line, "/" palette, "?" keys and the theme toggle all live in assets/css/command.css and assets/js/command.js. Front matter it reads, from the page first and then from the layout chain (Jekyll 3.10 merges layout front matter up the chain, child wins): c_home the home page: no top nav, no colophon, the prompt help c_section talks, writing, cv or now: the section hue and the nav mark c_kind post, page, index, doc or error: body class c- c_path what the prompt path shows after "~/" (default: c_section; for c_kind doc, the page URL) No third-party requests: the two faces are self-hosted woff2 (assets/fonts, OFL).
